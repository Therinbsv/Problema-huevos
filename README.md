# Problema-huevos
El proyecto resuelve el problema de los huevos con el modelo en espira. El problema consiste en un edificio de 100 pisos, con un número limitado de huevos, hay que encontrar el piso más bajo desde el que un huevo se rompe, usando el menor número de lanzamientos posible en el peor caso.
